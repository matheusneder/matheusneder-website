About

Technical depth with a business perspective

I'm a computer engineer, graduated from PUC Minas in Brazil, and I've been working in technology since 2003, when I started out as a freelance web developer and Linux systems administrator. Since then I've moved through product development, solutions architecture and software engineering — much of that time in financial institutions, where reliability, security and governance are not optional.

As an architect, I defined the architecture models for moving mainframe-based ecosystems to cloud-native applications, using hybrid architectures that allow a gradual migration without disrupting operations. I was also part of the rollout of one of the first on-premises Kubernetes clusters in Belo Horizonte, and of the redesign of services around an event-driven architecture on Apache Kafka.

Today, at TOTVS, I build a component that translates SQL statements at runtime, with the help of artificial intelligence, so that applications written for Microsoft SQL Server can also run on Oracle Database and PostgreSQL. I also contribute to the operations of TOTVS Cloud.

I aim to balance performance, scalability, interoperability and cost, and I give the same care to routine and urgent day-to-day problems. I work well in cross-functional, distributed teams, where technical leadership, mentoring and guidance on good practices are a natural part of the job.
